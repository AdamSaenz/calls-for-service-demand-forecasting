# Calls for Service Demand Forecasting

## Project Overview
This project analyzes San Antonio Police Department (SAPD) calls-for-service data to investigate patterns in service demand and explore how predictive analytics can support operational planning and resource allocation.

Developed as part of DSC680: Applied Data Science at Bellevue University, the project demonstrates the application of Python-based data analysis and predictive modeling to a public safety operations problem.

## Project Objectives
- Examine historical calls-for-service activity.
- Identify temporal patterns and fluctuations in service demand.
- Explore predictive modeling techniques for estimating future call volumes.
- Translate analytical findings into operational planning considerations.

## Data Sources
The project uses SAPD calls-for-service reports containing individual service records. The repository includes 24 source reports in `.aspx` format.

## Tools and Technologies
- Python
- Jupyter Notebook
- Data analysis and visualization
- Predictive modeling

## Repository Contents
- Jupyter notebook containing the project analysis
- 24 SAPD calls-for-service source reports
- README documentation

## Business Application
Forecasting calls-for-service demand can help public safety organizations anticipate workload fluctuations, evaluate staffing requirements, and make more informed resource allocation decisions.

## Limitations
